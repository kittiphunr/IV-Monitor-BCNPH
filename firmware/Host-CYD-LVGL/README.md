# เครื่องส่วนกลาง CYD แบบ LVGL v1.0.0 (TFT_eSPI + XPT2046_Touchscreen + LVGL)

สายนี้ใช้ชุดไลบรารีที่นิยมกับบอร์ด ESP32-2432S028 คือ **TFT_eSPI** (ขับจอ) + **XPT2046_Touchscreen** (ทัช)
+ **LVGL** (วาดหน้าจอ) แตกจากสาย `Host-CYD28` v1.4.0 ตรรกะการวัด การแจ้งเตือน ESP-NOW (Protocol v3)
และหน้าเว็บเหมือนกันทุกบรรทัด ผังหน้าจอแนวนอน 320×240 เหมือนสาย Host-CYD28 ทุกหน้า

> ## ⚠️ อ่านก่อนใช้: โค้ดฝั่ง LVGL ยังไม่เคยถูกคอมไพล์กับ LVGL จริง
> เครื่องมือบน PC ไม่มี LVGL ตรวจได้เฉพาะกับตัวแทน (mock) ที่ผมเขียนตามความเข้าใจ API ของ **LVGL 9.x**
> (`tools/screen-preview/lvgl.h`) ตัวแทนพิสูจน์ได้ว่าตรรกะและผังตำแหน่งถูก แต่ **ไม่พิสูจน์ว่าชื่อฟังก์ชันและพารามิเตอร์
> ของ LVGL จริงตรงกัน** ถ้าคอมไพล์ขึ้นข้อผิดพลาดเรื่องชื่อฟังก์ชันที่ไม่รู้จัก ให้เทียบเวอร์ชัน LVGL ก่อน
> และส่งข้อความผิดพลาดมาให้แก้ **ถ้าต้องการสายที่ผ่านการตรวจมากกว่า ให้ใช้ `Host-CYD28` ซึ่งไม่ใช้ LVGL**

## ต่างจากสาย Host-CYD28 อย่างไร

| เรื่อง | Host-CYD28 | Host-CYD-LVGL |
|---|---|---|
| ไลบรารีจอ | Adafruit หรือ TFT_eSPI (เลือกได้) | TFT_eSPI (ค่าตั้งในไฟล์ของไลบรารี) |
| ทัช | bit-bang เอง (`xpt2046_bitbang.h`) | **XPT2046_Touchscreen** บน VSPI ขา 25/39/32 |
| วาดหน้าจอ | วาดพิกเซลเอง | **LVGL** (วิตเจ็ต กล่อง ข้อความ แถบ) |
| การ์ด SD | ใช้ได้ (บันทึกรายนาทีและเหตุการณ์) | **ปิด** (`HOST_SD_ENABLED 0`) |
| ผังหน้าจอ | แนวนอนและแนวตั้ง | แนวนอนอย่างเดียว |

**ทำไมต้องปิด SD:** `XPT2046_Touchscreen` ต้องใช้บัส SPI ฮาร์ดแวร์ ส่วนบอร์ดนี้มีบัสให้ใช้ได้สองบัส จอใช้ HSPI
ทัชต้องใช้ VSPI ซึ่งเป็นบัสเดียวกับการ์ด SD (คนละขากัน ต้อง `begin()` ใหม่ทุกครั้งที่สลับ) จึงปิด SD ไว้ก่อน
ฟีเจอร์ดาวน์โหลดไฟล์จากหน้าเว็บจะแสดงว่าไม่มีการ์ด ถ้าต้องการ SD ให้ใช้สาย Host-CYD28

**LVGL เป็นชั้นวาดอย่างเดียว:** การแตะแต่ละหน้ายังเข้าฟังก์ชัน `handle*Tap` ตัวเดิมของสาย Host-CYD28 (LVGL ส่งพิกัดที่
แตะมาให้ แล้วโค้ดเดิมตัดสินว่าโดนปุ่มไหน) จึงใช้ตรรกะที่ผ่านชุดทดสอบการแตะแล้วซ้ำ

## ติดตั้งและตั้งค่า (ต้องทำครบก่อนคอมไพล์)

### 1. ไลบรารี (Library Manager)
- **TFT_eSPI** (Bodmer)
- **XPT2046_Touchscreen** (Paul Stoffregen)
- **lvgl** (kisvegabor / LVGL) เวอร์ชัน **9.x**
- **RTClib**

### 2. ค่าตั้ง TFT_eSPI (ตามชนิดจอ ดูจากจำนวนพอร์ต USB)
สำรอง `Documents/Arduino/libraries/TFT_eSPI/User_Setup.h` ไว้ก่อน แล้วคัดลอกไฟล์จากโฟลเดอร์ `tft_espi/` ไปทับ

| บอร์ด | ไฟล์ | ไดรเวอร์ |
|---|---|---|
| พอร์ต USB ช่องเดียว | `User_Setup.h` | `ILI9341_2_DRIVER` |
| **พอร์ต USB สองช่อง (Type-C + Micro-USB)** | `User_Setup_CYD2USB.h` (เปลี่ยนชื่อเป็น `User_Setup.h`) | `ST7789_DRIVER` + BGR + ปิดโหมดกลับสี |

ค่าตรงกับ [OttoMeister/ESP32-2432S028R](https://github.com/OttoMeister/ESP32-2432S028R) (`platformio.ini`) การทับไฟล์
กระทบทุกโปรเจ็กต์ที่ใช้ TFT_eSPI ในเครื่องเดียวกัน ไฟล์ไม่ประกาศ `TFT_BL` เพราะเฟิร์มแวร์คุมไฟหลังจอด้วย PWM เอง

### 3. ค่าตั้ง LVGL (`lv_conf.h`) — ถ้าข้ามขั้นนี้จะขึ้น `fatal error: ../../../../lv_conf.h: No such file or directory`
LVGL หาไฟล์ `lv_conf.h` ที่ `Documents/Arduino/libraries/lv_conf.h` (**ข้างโฟลเดอร์ `lvgl` ไม่ใช่ข้างใน**)

**วิธีง่าย (แนะนำ):** คัดลอกไฟล์สำเร็จรูป `lvgl_conf/lv_conf.h` ในโฟลเดอร์นี้ไปไว้ที่
`Documents/Arduino/libraries/lv_conf.h` ไฟล์นี้ตั้งเฉพาะค่าที่ต้องใช้ (จอ RGB565 และฟอนต์ Montserrat 12/16/20/28/48)
ค่าอื่นทั้งหมดใช้ค่าปริยายของ LVGL เอง

**วิธีละเอียด:** คัดลอก `lv_conf_template.h` ของไลบรารีไปเป็น `lv_conf.h` แล้วแก้ `#if 0` บนสุดเป็น `#if 1`,
`LV_COLOR_DEPTH` เป็น `16` และเปิด `LV_FONT_MONTSERRAT_12/16/20/28/48` เป็น `1` และตั้ง `LV_USE_STDLIB_MALLOC` / `LV_USE_STDLIB_STRING` / `LV_USE_STDLIB_SPRINTF` เป็น `LV_STDLIB_CLIB` (กัน DRAM ล้นตอนลิงก์)
ชื่อและค่าปริยายของตัวแปรอาจต่างตามเวอร์ชัน LVGL ให้ค้นชื่อในไฟล์เทมเพลตของเวอร์ชันที่ติดตั้ง

### 4. ตั้งค่าบอร์ดใน Arduino IDE
เหมือนสาย Host-CYD28: Board **ESP32 Dev Module**, Partition Scheme **Huge APP (3MB No OTA/1MB SPIFFS)**
แล้วอัปโหลด **ต้องเลือก Huge APP** เพราะพาร์ทิชันปริยายเล็กเกินไป (ดูตัวเลขจริงด้านล่าง)

### ขนาดโปรแกรมและหน่วยความจำ (ตัวเลขจริงจากการคอมไพล์ของผู้ใช้)

วัดโดยผู้ใช้บน Arduino IDE ด้วย ESP32 Arduino core 4.0.0, Board ESP32 Dev Module, สาย Host-CYD-LVGL รุ่น 1.0.1
(TFT_eSPI + XPT2046_Touchscreen + LVGL 9.x, ตั้ง `LV_STDLIB_CLIB`) ผมคัดตัวเลขจากข้อความของ Arduino IDE ไม่ได้วัดเอง

| รายการ | ค่าที่วัดได้ | เทียบกับพื้นที่ที่มี |
|---|---|---|
| โปรแกรม (Flash) | **1,775,663 ไบต์** | พาร์ทิชันปริยาย 1,310,720 ไบต์ = **135% (ล้น)** · Huge APP 3,145,728 ไบต์ = **ราว 56%** |
| ตัวแปรคงที่ (DRAM) | **98,112 ไบต์** (29%) | เหลือ 229,568 ไบต์ จากทั้งหมด 327,680 ไบต์ |

ข้อสังเกต: ก่อนตั้ง `LV_STDLIB_CLIB` ตัวแปรคงที่ล้น 39,200 ไบต์ (ขั้นลิงก์ไม่ผ่าน) เพราะ LVGL สำรองกอง 64 KB ไว้ในพื้นที่คงที่
ส่วนที่เหลือ 229,568 ไบต์ไม่ใช่ heap ว่างตอนรัน (Wi-Fi, เว็บเซิร์ฟเวอร์ และกองของ LVGL ที่จองตอนรันใช้จากส่วนนี้) การใช้ heap จริงตอนรันยังไม่ได้วัด

### 5. ใช้งานครั้งแรก
เข้าหน้า **SYSTEM → TOUCH CALIBRATION** แตะกากบาทสองจุดด้วยปลายปากกา ถ้าแตะแล้วสลับแกนหรือกลับด้านให้แก้
`TOUCH_SWAP_XY` / `TOUCH_FLIP_X` / `TOUCH_FLIP_Y` ที่หัวไฟล์ `Host-CYD-LVGL.ino`

## ปัญหาที่พบตอนคอมไพล์

| ข้อความผิดพลาด | สาเหตุ | วิธีแก้ |
|---|---|---|
| `fatal error: ../../../../lv_conf.h: No such file or directory` | ยังไม่มีไฟล์ตั้งค่า LVGL ที่ตำแหน่งที่ LVGL หา | คัดลอก `lvgl_conf/lv_conf.h` ไปไว้ที่ `Documents/Arduino/libraries/lv_conf.h` (ข้างโฟลเดอร์ `lvgl`) |
| `'VSPI_HOST' was not declared in this scope; did you mean 'SPI3_HOST'?` (ใน `TFT_eSPI_ESP32.c`) | TFT_eSPI 2.5.43 ยังใช้ชื่อเก่าที่ ESP32 Arduino core รุ่นใหม่ (เช่น 4.0.0) เอาออกแล้ว | ใช้ไฟล์ค่าตั้งจาก `tft_espi/` รุ่น 1.0.1 ขึ้นไป ซึ่งประกาศชื่อเดิมให้ชี้ไปที่ชื่อใหม่ (ไม่ต้องลด core ไม่ต้องแก้ไลบรารี) และต้อง **คัดลอกไปทับ** `Documents/Arduino/libraries/TFT_eSPI/User_Setup.h` จริง ๆ |
| `section .dram0.bss will not fit in region dram0_0_seg` / `DRAM segment data does not fit` | LVGL สำรองกองหน่วยความจำ 64 KB ไว้ในพื้นที่คงที่ (`LV_STDLIB_BUILTIN` ค่าปริยาย) | ใช้ไฟล์ `lvgl_conf/lv_conf.h` รุ่นล่าสุด ซึ่งตั้ง `LV_USE_STDLIB_MALLOC` เป็น `LV_STDLIB_CLIB` ให้ใช้ heap ของระบบ (ถ้าใช้วิธีละเอียดกับเทมเพลต ให้แก้สามค่า `LV_USE_STDLIB_MALLOC/STRING/SPRINTF` เป็น `LV_STDLIB_CLIB`) |
| `Multiple libraries were found for "SD.h"` | มีไลบรารี SD หลายชุดในเครื่อง | เป็นคำเตือน ไม่ใช่ข้อผิดพลาด ไม่ต้องแก้ |

ถ้าข้อความผิดพลาดเรื่อง `VSPI_HOST` ยังขึ้นหลังทับไฟล์แล้ว แปลว่า TFT_eSPI ยังไม่ได้อ่านไฟล์ของเรา ตรวจว่า
`Documents/Arduino/libraries/TFT_eSPI/User_Setup_Select.h` ยังเปิด `#include <User_Setup.h>` (ค่าปริยายของไลบรารี)
และไม่มีบรรทัด `#include <User_Setups/Setup...>` อื่นเปิดอยู่


### ทัชตอบสนองแต่ตำแหน่งผิด

1. **คาลิเบรตใหม่ทุกครั้ง** ที่เปลี่ยนทิศทางจอ (`TFT_ROTATION`) หรืออัปเดตเฟิร์มแวร์ข้ามรุ่น เข้า **SYSTEM → TOUCH CALIBRATION**
   แล้วแตะกากบาทสองจุด ค่าเก่าที่เก็บไว้ใช้กับทิศทางเดิมจะทำให้ตำแหน่งผิด
2. ตั้งแต่รุ่น 1.0.2 หน้าคาลิเบรต **ตรวจจับเองว่าแกนทัชสลับกับแกนจอหรือไม่** (ในแนวนอน) และกลับทิศของแต่ละแกนได้เองอยู่แล้ว
   จึงปกติไม่ต้องแก้ค่าในโค้ดอีก ทดสอบกับแผงทัชจำลองครบ 8 แบบ (สลับแกน x กลับ X x กลับ Y) แล้ว ส่วนบนบอร์ดจริงยังไม่ได้ทดสอบ
3. ถ้าหลังคาลิเบรตแล้วยังผิด ลองตั้ง `TOUCH_SWAP_XY` เป็น `1` ที่หัวไฟล์ (บังคับสลับแกน) แล้วอัปโหลดและคาลิเบรตใหม่ ในจอแนวตั้งตรวจเองไม่ได้
   (สองจุดสอบเทียบห่างกันเกือบเท่ากันทั้งสองแกน) ต้องใช้วิธีนี้
4. ใช้ปลายปากกา (stylus) แตะกากบาทตรงกลางให้แม่นที่สุด และแตะค้างนิ่งเล็กน้อย

## ตรวจบนเครื่อง PC

```bash
bash tools/lvgl-preview/run.sh       # คอมไพล์กับตัวแทน LVGL และเรนเดอร์ภาพหน้าจอทุกหน้า ลง docs/screens-lvgl/
bash tools/lvgl-tap-test/run.sh      # ชุดทดสอบการแตะเดิมของ Host-CYD28 + เส้นทางคลิก LVGL -> dispatchTap
```

ภาพจากตัวแทนใช้ฟอนต์บิตแมปประมาณแทน Montserrat จึงตรวจได้เฉพาะตำแหน่ง ซ้อนทับ และสี ไม่ใช่หน้าตาตัวอักษรจริง

## สิ่งที่ยังไม่ได้ทำ

**ยังไม่ได้ทดสอบบนฮาร์ดแวร์จริง** และ **ยังไม่เคยคอมไพล์กับ LVGL จริง** จุดเสี่ยงสูงสุดคือ
1. ชื่อและลายเซ็นฟังก์ชัน LVGL 9.x ที่เรียกใน `HostScreen.h` (`lv_display_*`, `lv_indev_*`, `lv_obj_*`, `lv_bar_*`)
2. การส่งภาพ `tft.pushColors(..., true)` ว่าสีไม่สลับไบต์ (ถ้าสีเพี้ยนเป็นสีแปลก ให้ลองเปลี่ยนพารามิเตอร์ตัวสุดท้ายเป็น `false`)
3. การใช้ heap ตอนรัน (LVGL + Wi-Fi + เว็บเซิร์ฟเวอร์พร้อมกัน) ยังไม่ได้วัด ขนาดโปรแกรมและตัวแปรคงที่วัดแล้ว (ดูหัวข้อขนาดด้านบน)
4. ผลของ `ts.tirqTouched()` เมื่อไม่ได้ต่อขา IRQ (บอร์ดนี้ต่อ GPIO36 ไว้แล้ว)
