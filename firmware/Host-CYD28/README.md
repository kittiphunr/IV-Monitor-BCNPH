# Host บอร์ด CYD (ESP32-2432S028) — เขียนใหม่ ด่านที่ 2: แกนเครือข่าย v2.0.1

**รุ่นนี้ยังไม่ใช่ Host เต็มรูป** ไม่มีเว็บแดชบอร์ดหรือหน้าเตียงสุดท้าย (ใช้ตารางตัวอักษรกับคำสั่ง Serial แทน) เป็นสเก็ตช์พิสูจน์ฮาร์ดแวร์และเครือข่าย
ของการเขียน `Host-CYD28` ใหม่ทั้งหมด (ไม่นำโค้ดรุ่น 1.x มาปรับ) รุ่น 1.x ยังอยู่ใน `main` และในแบรนช์ `release/*`

| ด่าน | เนื้อหา | สถานะ |
|---|---|---|
| 1 | จอ ไฟหลังจอ ทัช คาลิเบรต | เสร็จ (ผ่านตัวจำลองบน PC ยังไม่ได้ลองบนบอร์ดจริง) |
| 2 | ESP-NOW แพ็กเก็ต v3 ตารางเตียง รหัสเตือน NVS | **ไฟล์นี้** (ผ่านตัวจำลองบน PC ยังไม่ได้ลองกับ Station จริง) |
| 3 | หน้าจอ HOME / BED / BED SET / NUMPAD / SYSTEM | ยังไม่เริ่ม |
| 4 | เว็บแดชบอร์ด RTC SD ประวัติ | ยังไม่เริ่ม |

## ไฟล์

| `bed_model.h` | ตรรกะล้วน: ออนไลน์ รหัสเตือน ขาดการติดต่อ คุณภาพลิงก์ เลขเตียงซ้ำ ตัวจัดช่องเวลาส่ง Sync |
| `bed_store.h` | เก็บค่าตั้งเตียงและ `resetSeq` ใน NVS |
| `espnow_link.h` | ESP-NOW: callback ใส่คิววงแหวน `loop()` ดึงไปประมวลผล ส่ง Sync แบบกระจาย |

## ด่านที่ 2: ใช้งานกับ Station

1. อัปโหลด บอร์ดเริ่ม ESP-NOW ที่ช่อง 1 (`CYD_ESPNOW_CHANNEL`) ทันที ไม่ต้องคาลิเบรตก่อน หน้าจอแสดงตารางเตียง
2. ตั้งค่าเตียงทาง Serial (115200 จบบรรทัดด้วย Enter) ค่าถูกเก็บใน NVS และส่งให้ Station ทันที:
   `beds 5` จำนวนเตียงที่เปิดใช้ (1-8) · `rate 1 60` เป้าหมาย mL/h · `plan 1 500` ปริมาตรตามแผน mL ·
   `df 1 20` drop factor (10/15/20/60) · `near 1 80` เกณฑ์ใกล้หมด % · `newbag 1` เริ่มถุงใหม่ · `ack 1` รับทราบใกล้หมด · `table` พิมพ์ตาราง
3. Station เปิดแล้วควรเห็นเตียงขึ้น OK ภายในไม่กี่วินาที ถ้า Station ค้นหาช่องอยู่ มันจะหาช่อง 1 เจอเอง
4. `m` หรือกด BOOT สั้นๆ สลับไปหน้าทดสอบจอ/ทัช (ด่านที่ 1) กด BOOT ค้าง 1.5 วินาที = คาลิเบรตใหม่

**พฤติกรรมที่ตรงกับ Host รุ่นเดิม** (เพื่อให้ Station ทุกรุ่นคุยได้): ออฟไลน์เมื่อเงียบเกิน 8 วินาที · ขาดการติดต่อจริงเมื่อเงียบต่ออีก 30 วินาที
(เฉพาะเตียงที่กำลังนับ) · สายพับเมื่อไม่มีหยดเกิน 2.5 เท่าของช่วงหยดตามเป้า (ขั้นต่ำ 8 วินาที เพดาน 5 นาที) · เร็ว/ช้าเกินเมื่อเกิน 135%/ต่ำกว่า 65% ของเป้าต่อเนื่อง 20 วินาที
· ไม่มีหยดเลย 90 วินาที · ใกล้หมดที่ 80% (ตั้งได้ 50-95) · รหัส 6 (NO_SIGNAL) กับ 7 (LOST_LINK) ใช้ภายใน Host ไม่ถูกส่งไป Station

**ยังไม่มีในด่านนี้:** เสียงเตือนของ Host, นาฬิกา/ซิงก์เวลาให้ Station (ส่ง `epochTime=0` ซึ่ง Station เมิน), SoftAP/เว็บ (ด่านที่ 4), หน้าจอสุดท้าย (ด่านที่ 3)

## วิธีทดสอบบนบอร์ด (ด่านที่ 1: จอและทัช)

1. เลือกชิปจอตามพอร์ต USB: **ช่องเดียว = ILI9341** (ค่าปริยาย) · **สองช่อง = ST7789** แก้ `CYD_PANEL` ใน `board.h` เป็น `7789`
2. อัปโหลด เปิด Serial Monitor 115200 บอร์ดจะเข้าหน้าคาลิเบรตเอง (ยังไม่มีค่าในเครื่อง) แตะกากบาทสามจุดตามลำดับ
3. หน้าทดสอบแสดงแถบสี 8 สี ไล่เฉดเทา 16 ระดับ และช่องวาดตามนิ้ว ตรวจ:
   - **ดำต้องดำสนิท** (ช่องซ้ายสุดของไล่เฉดและแถบสุดท้าย) ถ้าซีดหรือเทา พิมพ์ `i` ใน Serial เพื่อสลับกลับสี
   - **แดง/น้ำเงินไม่สลับ** ถ้าสลับ พิมพ์ `b` (ใช้ได้กับ ST7789)
   - จุดสีเหลืองต้องตามปลายนิ้วตรงตำแหน่ง ถ้าเพี้ยนแตะ CAL หรือกด BOOT ค้าง 1.5 วินาที
4. ได้ค่าที่ถูกแล้วให้ตั้ง `CYD_INVERT` / `CYD_BGR` ใน `board.h` ตามนั้นแล้วอัปโหลดใหม่ (ค่าที่สลับผ่าน Serial หายเมื่อรีเซ็ต)

| คำสั่ง Serial | ผล |
|---|---|
| `h` | ช่วยเหลือ |
| `i` | สลับโหมดกลับสี |
| `b` | สลับ RGB/BGR (ST7789) |
| `r` | เปลี่ยนทิศจอ แล้วคาลิเบรตใหม่ |
| `c` | คาลิเบรตใหม่ |
| `+` / `-` | ความสว่างไฟหลังจอ |
| `d` | พิมพ์รหัสชิป ILI9341 (ควรได้ `00 93 41`) |

## ต่างจากรุ่น 1.x อย่างไร

- **คาลิเบรตแบบ affine สามจุด** แทนการเดาว่าแกนทัชสลับหรือไม่ จึงรองรับแกนสลับ กลับด้าน และเอียงในสมการเดียว
  ปฏิเสธจุดที่อยู่แนวเดียวกันหรือแตะที่เดิมซ้ำ ค่าที่เก็บใน NVS ผูกกับทิศจอ ขนาดจอ และชิปจอ ถ้าไม่ตรงจะคาลิเบรตใหม่เอง
- **ตัวติดตามนิ้ว** กรองสัญญาณสะดุดของทัชราคาถูก (ต้องเห็นกดสองครั้งติดกันจึงนับเป็น DOWN)
- **สวิตช์สีขณะรัน** หาค่าที่ถูกกับบอร์ดแต่ละใบได้โดยไม่ต้องคอมไพล์ใหม่

## การตรวจ

```bash
bash tools/cyd-board-test/run.sh    # ด่านที่ 1 + รันสเก็ตช์ทั้งไฟล์กับ ESP-NOW จำลอง (Sync ด่วน แพ็กเก็ตเสีย คิวล้น)
bash tools/cyd-bed-test/run.sh      # ด่านที่ 2: ตรรกะเตียงล้วน (ออนไลน์ เตือน ขาดการติดต่อ ตัวจัดช่องเวลา เวลาวนรอบ)
```

ตรวจคณิตศาสตร์คาลิเบรตกับแกนสามแบบ การปฏิเสธจุดเสีย ไดรเวอร์กับแบบจำลองชิป XPT2046 และรัน `setup()`/`loop()`
ของสเก็ตช์จริงกับชิปจำลองที่แตะเป้าหมายคาลิเบรตเอง ทั้ง `CYD_PANEL` 9341 และ 7789

**ยังไม่ได้ทดสอบบนฮาร์ดแวร์จริง** โดยเฉพาะค่าสีของ ST7789 (`CYD_INVERT` / `CYD_BGR`) ที่ต้องยืนยันด้วยตาบนบอร์ดจริง
