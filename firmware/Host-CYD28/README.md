# เครื่องส่วนกลาง บอร์ด CYD (ESP32-2432S028) จอสัมผัส 2.8" v1.4.0

## ตรวจก่อน: บอร์ดของคุณเป็นรุ่นไหน (สำคัญที่สุดสำหรับเรื่องจอ)

บอร์ดตระกูล ESP32-2432S028 มี **สองรุ่นที่ใช้ขาเหมือนกันแต่ชิปจอต่างกัน** ดูจากจำนวนพอร์ต USB

| รุ่น | พอร์ต USB | ชิปจอ | ต้นแบบอ้างอิง (platformio env) |
|---|---|---|---|
| ล็อตเดิม | **ช่องเดียว** (Micro-USB) | ILI9341 | `cyd`: `ILI9341_2_DRIVER` |
| ล็อตใหม่ | **สองช่อง** (Type-C + Micro-USB) | **ST7789** | `cyd2usb`: `ST7789_DRIVER` + `TFT_RGB_ORDER=TFT_BGR` + `TFT_INVERSION_OFF` |

อ้างอิง: [OttoMeister/ESP32-2432S028R](https://github.com/OttoMeister/ESP32-2432S028R) (`platformio.ini`)
และ [witnessmenow/ESP32-Cheap-Yellow-Display](https://github.com/witnessmenow/ESP32-Cheap-Yellow-Display)
อาการเมื่อตั้งผิดรุ่น: **สีซีด ภาพไม่เต็มจอ ภาพกลับด้าน สีเพี้ยน**

### ตั้งค่าที่หัวไฟล์ `Host-CYD28.ino`

| บอร์ด | วิธีที่แนะนำ | ตั้งค่า |
|---|---|---|
| **พอร์ต USB ช่องเดียว (ILI9341)** | ไลบรารี Adafruit (ไม่ต้องคัดลอกไฟล์) | `TFT_LIB 0` + `TFT_CONTROLLER 9341` (ปริยาย) |
| **พอร์ต USB สองช่อง (ST7789)** วิธี A | ไลบรารี Adafruit | `TFT_LIB 0` + `TFT_CONTROLLER 7789` (ปริยายสีเป็น BGR และปิดโหมดกลับสีแล้ว) |
| **พอร์ต USB สองช่อง (ST7789)** วิธี B | TFT_eSPI ตามต้นแบบ | `TFT_LIB 1` + คัดลอก `tft_espi/User_Setup_CYD2USB.h` (ตามขั้นตอนด้านล่าง) |

วิธี B ตรงกับต้นแบบที่พิสูจน์แล้วมากที่สุด ถ้าวิธี A ยังเพี้ยนให้ใช้วิธี B ถ้าสลับแดง/น้ำเงินในวิธี A ให้ตั้ง `TFT_BGR` เป็น `0`
ถ้าสีกลับด้าน (ดำเป็นขาว) ให้ตั้ง `TFT_INVERT` เป็น `1`

**วิธีใช้ `TFT_LIB 1` (TFT_eSPI)**
1. ติดตั้งไลบรารี **TFT_eSPI** (โดย Bodmer) ผ่าน Library Manager
2. **สำรองไฟล์เดิม** `Documents/Arduino/libraries/TFT_eSPI/User_Setup.h` ไว้ก่อน
3. คัดลอกไฟล์จาก `firmware/Host-CYD28/tft_espi/` ไปทับไฟล์นั้นแล้วเปลี่ยนชื่อเป็น `User_Setup.h`
   - บอร์ดสองพอร์ต USB (ST7789): ใช้ `User_Setup_CYD2USB.h`
   - บอร์ดพอร์ตเดียว (ILI9341): ใช้ `User_Setup.h`
4. ที่หัวไฟล์ `Host-CYD28.ino` เปลี่ยน `#define TFT_LIB 0` เป็น `1` แล้วอัปโหลด

ข้อควรรู้: TFT_eSPI อ่านค่าตั้งจากไฟล์ในโฟลเดอร์ไลบรารีเท่านั้น การทับไฟล์กระทบทุกโปรเจ็กต์ที่ใช้ไลบรารีนี้ในเครื่องเดียวกัน
ถ้าเลือก `TFT_LIB 1` แล้ว `TFT_CONTROLLER` กับ `TFT_BGR` จะไม่มีผล ชิปจอและลำดับสีกำหนดจากไฟล์ค่าตั้ง
`TFT_BL` ไม่ได้ประกาศในไฟล์ค่าตั้ง เพราะเฟิร์มแวร์คุมไฟหลังจอด้วย PWM เอง

**หมายเหตุความถูกต้อง:** ค่าของรุ่น ST7789 ยกจากไฟล์ `platformio.ini` ของโปรเจ็กต้นแบบ ส่วนวิธี A ที่สั่ง BGR ผ่านไลบรารี Adafruit
ผมเขียนเองตามตารางหมุนจอของไลบรารี ยังไม่ได้ยืนยันกับบอร์ดจริง

## ปัญหาที่พบตอนคอมไพล์

| ข้อความผิดพลาด | สาเหตุ | วิธีแก้ |
|---|---|---|
| `'VSPI_HOST' was not declared in this scope; did you mean 'SPI3_HOST'?` (ใน `TFT_eSPI_ESP32.c`) | TFT_eSPI 2.5.43 ยังใช้ชื่อเก่าที่ ESP32 Arduino core รุ่นใหม่ (เช่น 4.0.0) เอาออกแล้ว | ใช้ไฟล์ค่าตั้งจาก `tft_espi/` รุ่น 1.4.1 ขึ้นไป (ใช้เมื่อ `TFT_LIB 1`) ซึ่งประกาศชื่อเดิมให้ชี้ไปที่ชื่อใหม่ (ไม่ต้องลด core ไม่ต้องแก้ไลบรารี) และต้อง **คัดลอกไปทับ** `Documents/Arduino/libraries/TFT_eSPI/User_Setup.h` จริง ๆ |
| `Multiple libraries were found for "SD.h"` | มีไลบรารี SD หลายชุดในเครื่อง | เป็นคำเตือน ไม่ใช่ข้อผิดพลาด ไม่ต้องแก้ |

ถ้าข้อความผิดพลาดเรื่อง `VSPI_HOST` ยังขึ้นหลังทับไฟล์แล้ว แปลว่า TFT_eSPI ยังไม่ได้อ่านไฟล์ของเรา ตรวจว่า
`Documents/Arduino/libraries/TFT_eSPI/User_Setup_Select.h` ยังเปิด `#include <User_Setup.h>` (ค่าปริยายของไลบรารี)
และไม่มีบรรทัด `#include <User_Setups/Setup...>` อื่นเปิดอยู่

เครื่องมือหาชิปจอที่ถูกต้อง: ใช้สเก็ตช์ `firmware/CYD-ScreenTest/` ก่อน มันสลับโหมดจอสี่แบบและพิมพ์รหัสชิปทาง Serial

# เครื่องส่วนกลาง บอร์ด CYD v1.1.0 — หน้าจอแนวนอน

รุ่น 1.1.0 เปลี่ยนเป็น **หน้าจอแนวนอน 320×240** เป็นค่าปริยาย (รุ่น 1.0.0 เป็นแนวตั้ง) จัดผังใหม่ทุกหน้า
ให้ใช้พื้นที่กว้างได้เต็มที่ ภาพทุกหน้าอยู่ใน `docs/screens-cyd/`

| หน้า | ผังแนวนอน |
|---|---|
| HOME | ซ้าย = เตียงที่ต้องดูตัวใหญ่พร้อมเวลาที่เหลือ · ขวา = รายการเตียงอื่น (แตะเพื่อเปิด) · ล่าง = แถบสรุปกับปุ่ม SET |
| BED | การ์ดบนมีอัตราไหล กระเปาะหยด และสถานะลิงก์ · การ์ดล่างมีแถบความคืบหน้า · ปุ่มสามปุ่มเรียงแถวล่าง |
| BED SET | ช่องตั้งค่าสี่ช่องเรียงเป็นตาราง 2×2 · SAVE/CANCEL ปุ่มใหญ่ด้านล่าง |
| NUMPAD | ช่องค่าอยู่ซ้าย แป้นตัวเลขอยู่ขวา |
| SYSTEM | ช่องตั้งค่าสองช่องเคียงกัน การ์ดข้อมูลแบ่งสองคอลัมน์ (เครือข่าย / นาฬิกาและ SD) |

ในรายการเตียงแนวนอน **ไม่แสดงชื่อผู้ป่วย** เพราะแถวแคบเกินไป ดูชื่อได้ที่หน้า BED

เลือกทิศทางที่หัวไฟล์ `Host-CYD28.ino` ด้วย `TFT_ROTATION`: `1` แนวนอน (ปริยาย) · `3` แนวนอนกลับด้าน
(ใช้เมื่อตั้งบอร์ดกลับหัวแล้วพอร์ต USB อยู่ผิดฝั่ง) · `0` แนวตั้งแบบเดิม · `2` แนวตั้งกลับด้าน

**เปลี่ยนทิศทางแล้วต้องเข้า SYSTEM → CALIBRATE ใหม่ทุกครั้ง** เพราะค่าปรับทัชที่เก็บไว้ใช้กับทิศทางเดิม

# เครื่องส่วนกลาง บอร์ด CYD v1.0.0 (ข้อความรุ่นแรก)

เฟิร์มแวร์ Host สำหรับบอร์ดสำเร็จรูป **ESP32-2432S028** (รู้จักกันในชื่อ *Cheap Yellow Display*)
ที่รวมทุกอย่างไว้ในแผ่นเดียว ไม่ต้องต่อสายจอและทัชเอง

| ในบอร์ด | รายละเอียด |
|---|---|
| ไมโครคอนโทรลเลอร์ | ESP32-WROOM-32 (ESP32 รุ่นปกติ ไม่ใช่ S3, ไม่มี PSRAM) |
| จอ | ILI9341 2.8" 240×320 สี |
| ทัช | XPT2046 แบบความต้านทาน |
| การ์ด SD | ช่อง TF ในตัว |
| เสียง | ขั้ว SPEAK ผ่านวงจรขยายบนบอร์ด (ต้องเสียบลำโพงเอง) |
| ไฟ RGB / LDR | ไม่ได้ใช้ในเฟิร์มแวร์นี้ |

เป็น **Host สายที่สี่** ต่อจาก OLED, TFT 2.8" และสัมผัส 2.4" เลือกใช้ตัวเดียวคู่กับ Station สายใดก็ได้

## ต่างจาก Host จอสัมผัส 2.4" อย่างไร

ตรรกะการวัด การแจ้งเตือน ESP-NOW (Protocol v3) หน้าเว็บ และหน้าจอทุกหน้า
**เหมือนกับ Host จอสัมผัส 2.4" v4.10.1 ทุกบรรทัด** `HostScreen.h` และ `web_dashboard.h`
เป็นสำเนาตรงตัวในรุ่น 1.0.0 (ใช้จอแนวตั้ง 240×320 เท่ากัน) รุ่น 1.1.0 เพิ่มผังแนวนอนเข้าไป ส่วนอื่นที่เปลี่ยนมีเฉพาะส่วนที่ผูกกับฮาร์ดแวร์

| เรื่อง | รุ่น 2.4" (ESP32-S3) | รุ่นนี้ (CYD) |
|---|---|---|
| ไดรเวอร์จอ | Adafruit_ST7789 | Adafruit_ILI9341 (ลำดับพารามิเตอร์ DC ก่อน CS) |
| บัสจอ | FSPI | HSPI |
| ทัช | ไลบรารี XPT2046_Touchscreen บนบัสเดียวกับจอ | อ่านแบบ bit-bang เอง (`xpt2046_bitbang.h`) ขาแยก |
| SD card | ใช้บัสร่วมกับจอ | VSPI ขาของมันเอง |
| ปุ่ม | ต่อเพิ่มเอง GPIO4 | ปุ่ม BOOT บนบอร์ด (GPIO0) |
| แบตเตอรี่ | วัดแรงดันได้ | ไม่มีวงจรวัด แสดงเป็นเสียบไฟตลอด |

**ที่ต้อง bit-bang เพราะ** ทัชของบอร์ดนี้ใช้ขา SPI แยกจากจอ และ SD ก็ใช้อีกบัส
ขณะที่ ESP32 รุ่นปกติมีบัสให้ใช้ได้แค่ HSPI กับ VSPI สองบัส ไม่มีบัสที่สามให้ไลบรารีทัช

## ผังขา (เดินสายมาจากโรงงานแล้ว ไม่ต้องต่ออะไร)

| หน้าที่ | GPIO |
|---|---|
| จอ SCK / MOSI / MISO / CS / DC / RST | 14 / 13 / 12 / 15 / 2 / (ต่อกับ EN) |
| ไฟหลังจอ (PWM) | 21 |
| ทัช CLK / MOSI / MISO / CS / IRQ | 25 / 32 / 39 / 33 / 36 |
| SD SCK / MISO / MOSI / CS | 18 / 19 / 23 / 5 |
| ลำโพง | 26 |
| ปุ่ม BOOT (ปุ่มเปิด-ปิดจอ / พักเสียง) | 0 |

### ต่ออุปกรณ์เพิ่ม: นาฬิกา DS3231 (ไม่บังคับ)

ช่อง **CN1** บนบอร์ดมี `GND / IO22 / IO27 / 3V3` ตรงกับโมดูล DS3231 พอดี

| DS3231 | CN1 |
|---|---|
| GND | GND |
| VCC | 3V3 |
| SDA | IO27 |
| SCL | IO22 |

ถ้าไม่ต่อ เครื่องทำงานได้ตามปกติ แค่เวลาจะไม่คงอยู่เมื่อไฟดับ จนกว่าจะเปิดหน้าเว็บจากมือถือเพื่อตั้งเวลา

## วิธีแฟลช (Arduino IDE)

ไลบรารีที่ต้องติดตั้ง: **Adafruit GFX**, **Adafruit ILI9341**, **RTClib**
(ไม่ต้องติดตั้ง XPT2046_Touchscreen เพราะรุ่นนี้ไม่ใช้)

| ตั้งค่า | ค่า |
|---|---|
| Board | ESP32 Dev Module |
| Partition Scheme | **Huge APP (3MB No OTA/1MB SPIFFS)** |
| Upload Speed | 460800 (ถ้าอัปโหลดไม่ผ่านให้ลด) |

### ขนาดโปรแกรมและหน่วยความจำ (ตัวเลขจริงจากการคอมไพล์ของผู้ใช้)

รุ่น S3 มีแฟลช 16 MB แต่บอร์ดนี้มี 4 MB พาร์ทิชันปริยาย (1.3 MB) **ไม่พอ** ต้องเลือก Huge APP
ตัวเลขด้านล่างวัดโดยผู้ใช้บน Arduino IDE (Board ESP32 Dev Module, ESP32 Arduino core 4.0.0) ผมคัดจากข้อความของ Arduino IDE ไม่ได้วัดเอง

| สาย / ไลบรารีจอ | โปรแกรม (Flash) | ตัวแปรคงที่ (DRAM) |
|---|---|---|
| Host-CYD28 รุ่นแรก ๆ (Adafruit) | **1,329,519 ไบต์** = 101% ของพาร์ทิชันปริยาย 1,310,720 (ล้น) · ราว **42%** ของ Huge APP (3,145,728) | 81,636 ไบต์ (24%) |

ตัวเลขนี้วัดจากรุ่นแรก ๆ ของสายนี้ (ก่อนเพิ่มตัวเลือกไลบรารีจอ) รุ่นล่าสุดไม่ได้วัดใหม่ ขนาดอาจต่างเล็กน้อย
ส่วนสาย Host-CYD-LVGL ใหญ่กว่ามาก (1.78 MB) ดูใน `firmware/Host-CYD-LVGL/README.md

## ใช้งานครั้งแรก

1. เปิดเครื่อง แล้วเข้า **SYSTEM → CALIBRATE** แตะสองมุมตามจุดที่ขึ้นบนจอ
   ค่าปรับความแม่นเริ่มต้นเป็นค่ากลาง ๆ ของโมดูลทั่วไป ทัชของบอร์ดนี้อาจกลับแกนหรือคลาดได้
2. ถ้าหลังปรับแล้วแตะยังสลับแกน ให้แก้ `TOUCH_SWAP_XY` / `TOUCH_FLIP_X` / `TOUCH_FLIP_Y`
   ที่หัวไฟล์ `Host-CYD28.ino`
3. ถ้าภาพกลับหัว ให้ตั้ง `TFT_ROTATION` เป็น `3` (แนวนอน) หรือ `2` (แนวตั้ง)


### ทัชตอบสนองแต่ตำแหน่งผิด

1. **คาลิเบรตใหม่ทุกครั้ง** ที่เปลี่ยนทิศทางจอ (`TFT_ROTATION`) หรืออัปเดตเฟิร์มแวร์ข้ามรุ่น เข้า **SYSTEM → TOUCH CALIBRATION**
   แล้วแตะกากบาทสองจุด ค่าเก่าที่เก็บไว้ใช้กับทิศทางเดิมจะทำให้ตำแหน่งผิด
2. ตั้งแต่รุ่น 1.4.2 หน้าคาลิเบรต **ตรวจจับเองว่าแกนทัชสลับกับแกนจอหรือไม่** (ในแนวนอน) และกลับทิศของแต่ละแกนได้เองอยู่แล้ว
   จึงปกติไม่ต้องแก้ค่าในโค้ดอีก ทดสอบกับแผงทัชจำลองครบ 8 แบบ (สลับแกน x กลับ X x กลับ Y) แล้ว ส่วนบนบอร์ดจริงยังไม่ได้ทดสอบ
3. ถ้าหลังคาลิเบรตแล้วยังผิด ลองตั้ง `TOUCH_SWAP_XY` เป็น `1` ที่หัวไฟล์ (บังคับสลับแกน) แล้วอัปโหลดและคาลิเบรตใหม่ ในจอแนวตั้งตรวจเองไม่ได้
   (สองจุดสอบเทียบห่างกันเกือบเท่ากันทั้งสองแกน) ต้องใช้วิธีนี้
4. ใช้ปลายปากกา (stylus) แตะกากบาทตรงกลางให้แม่นที่สุด และแตะค้างนิ่งเล็กน้อย

## ข้อควรระวัง

* **ห้ามกดค้างปุ่ม BOOT ตอนจ่ายไฟหรือกด RST** บอร์ดจะเข้าโหมดโปรแกรมแทนการบูตปกติ
  กดปุ่มนี้ตอนเครื่องทำงานอยู่ใช้ได้ตามปกติ
* **บอร์ดล็อตใหม่บางล็อตใช้จอ ST7789 แทน ILI9341** (มักมีพอร์ต USB สองช่อง Type-C + Micro-USB)
  อาการเมื่อใช้ไดรเวอร์ผิดชนิด: **สีซีด ภาพไม่เต็มจอ สีกลับด้าน หรือจอขาว** วิธีแก้ที่หัวไฟล์ `Host-CYD28.ino`
  1. ตั้ง `TFT_CONTROLLER` เป็น `7789` แล้วอัปโหลดใหม่ (รุ่น 1.2.0 ขึ้นไป)
  2. ถ้าสีกลับด้าน (ดำเป็นขาว) ให้ตั้ง `TFT_INVERT` เป็น `1` เพิ่ม ค่านี้หมายถึง "สลับจากค่าปริยายของไลบรารี" ทั้งสองชิป
* บอร์ดนี้ไม่มีขาต่อแบตเตอรี่ ต้องจ่ายไฟทาง USB ตลอด
* ลำโพงต้องเสียบที่ขั้ว SPEAK ถ้าไม่เสียบจะไม่มีเสียงเตือนเลย ซึ่งเป็นความเสี่ยงด้านความปลอดภัย
  ให้ทดสอบเสียงก่อนใช้งานทุกครั้ง

## ตรวจบนเครื่อง PC

```bash
bash tools/cyd-preview/run.sh        # คอมไพล์และเรนเดอร์ภาพหน้าจอทุกหน้าลง docs/screens-cyd/
bash tools/cyd-touch-test/run.sh     # ไดรเวอร์ทัช bit-bang กับแบบจำลองชิป XPT2046
bash tools/cyd-tap-test/run.sh       # แตะตรงปุ่มจริงทุกหน้า ทั้งแนวนอนและแนวตั้ง
CYD_ROT=0 bash tools/cyd-preview/run.sh /tmp/port   # เรนเดอร์ผังแนวตั้งเดิมเพื่อเทียบ
CYD_LIB=1 bash tools/cyd-preview/run.sh /tmp/espi    # ตรวจว่าตัวเลือก TFT_eSPI คอมไพล์ผ่าน
```

ผังแนวตั้ง (`CYD_ROT=0`) ให้ภาพเหมือนรุ่น 1.0.0 ทุกพิกเซล ซึ่งเหมือนรุ่น 2.4" ยกเว้นไอคอนแบตเตอรี่
(รุ่นนี้ไม่มีวงจรวัดแบต จึงแสดงเต็มตลอด) ผังแนวนอนเป็นของใหม่ ตรวจด้วยตาและด้วย `tools/cyd-tap-test`

## สิ่งที่ยังไม่ได้ทำ

**ยังไม่ได้ทดสอบบนฮาร์ดแวร์จริง** ตรวจด้วยเครื่องมือจำลองบนเครื่อง PC เท่านั้น
โดยเฉพาะสามจุดที่เสี่ยงที่สุดเมื่อขึ้นบอร์ดจริง

1. **ไดรเวอร์ทัช bit-bang** ทดสอบกับแบบจำลองชิปที่เขียนจากดาต้าชีตเท่านั้น
   ถ้าค่าทัชเพี้ยนผิดปกติ ให้เริ่มสงสัยที่นี่ก่อน
2. **ขนาดโปรแกรมเทียบกับพาร์ทิชัน** วัดแล้วจากรุ่นแรก ๆ (1.33 MB ต้องใช้ Huge APP) รุ่นล่าสุดยังไม่ได้วัดใหม่
3. **ผังขา** ยกจากเอกสารเผยแพร่ของบอร์ด ESP32-2432S028 ล็อตที่ใช้ ILI9341 ตามภาพสินค้า
