# Host บอร์ด CYD (ESP32-2432S028) — เขียนใหม่ ครบสี่ด่าน v2.0.5

**ครบสี่ด่านแล้ว** หน้าจอสัมผัส เสียงเตือน เครือข่าย ESP-NOW เว็บแดชบอร์ด นาฬิกา ประวัติเหตุการณ์ และบันทึกลง SD ผ่านตัวจำลองบน PC ทั้งหมด **ยังไม่ได้ทดสอบกับ Station และบอร์ดจริง** รุ่น 1.x ยังอยู่ใน `main` และแบรนช์ `release/*`
ของการเขียน `Host-CYD28` ใหม่ทั้งหมด (ไม่นำโค้ดรุ่น 1.x มาปรับ) รุ่น 1.x ยังอยู่ใน `main` และในแบรนช์ `release/*`

| ด่าน | เนื้อหา | สถานะ |
|---|---|---|
| 1 | จอ ไฟหลังจอ ทัช คาลิเบรต | เสร็จ (ผ่านตัวจำลองบน PC ยังไม่ได้ลองบนบอร์ดจริง) |
| 2 | ESP-NOW แพ็กเก็ต v3 ตารางเตียง รหัสเตือน NVS | เสร็จ (ผ่านตัวจำลองบน PC ยังไม่ได้ลองกับ Station จริง) |
| 3 | หน้าจอ HOME / BED / BED SET / NUMPAD / SYSTEM และเสียงเตือน | เสร็จ (ผ่านตัวจำลองบน PC ยังไม่ได้ลองบนบอร์ดจริง) |
| 4 | เว็บแดชบอร์ด นาฬิกา SD ประวัติเหตุการณ์ | **ไฟล์นี้** (ผ่านตัวจำลองบน PC ยังไม่ได้ลองบนบอร์ดจริง) |

## หน้าเปิดเครื่อง (โลโก้) v2.0.5

เปิดเครื่องแล้วขึ้นโลโก้วิทยาลัยบนพื้นสีดำทันที (ก่อนเริ่ม Wi-Fi และ ESP-NOW) พร้อม **แถบโหลดสไตล์ Windows XP** ที่ด้านล่าง:
กรอบมนมีบล็อกสีน้ำเงินสามก้อนวิ่งจากซ้ายไปขวาวนซ้ำ ขยับต่อเนื่องแม้ขั้นเริ่มระบบ (โดยเฉพาะการ์ด SD) ใช้เวลานาน
แถบนี้บอกว่าเครื่องยังทำงานอยู่ ไม่ได้บอกเปอร์เซ็นต์ความคืบหน้าจริง โลโก้ค้างนาน `CYD_SPLASH_MS` (ปริยาย 2.5 วินาที นับจากตอนวาด ไม่ใช่จากตอนเริ่มระบบเสร็จ) แตะจอเพื่อข้ามได้ ตั้งเป็น `0` เพื่อปิดหน้านี้
ระหว่างโลโก้ค้าง ระบบรับข้อมูลจาก Station เข้าคิวตามปกติ

ภาพต้นฉบับอยู่ที่ `docs/logo/phrae-technical-college.png` เปลี่ยนโลโก้ด้วยคำสั่ง:

```bash
python3 tools/logo-convert/make_logo.py ภาพใหม่.png --size 300x200 --bg 000000 --out firmware/Host-CYD28/logo.h
```

ภาพถูกย่อให้พอดีกรอบโดยคงสัดส่วน (พื้นโปร่งใสวางบนสีดำ) ขนาด 300×200 ใช้ flash 120,000 ไบต์ ต้องเหลือที่ว่างด้านล่างประมาณ 30 พิกเซลสำหรับแถบโหลด
ไม่มีไฟล์ `logo.h` ก็คอมไพล์ได้ (แสดงชื่อระบบเป็นตัวอักษรแทน) ภาพตัวอย่างอยู่ที่ `docs/screens-cyd2/splash.png` และ `splash_progress.png`

## NO DROP ถึงเครื่องประจำเตียง (v2.0.4)

NO DROP คือเตียงที่ออนไลน์และกำลังนับ แต่เซนเซอร์ไม่เคยจับหยดเลยนาน 90 วินาที (ต่างจากสายพับซึ่งคือเคยไหลแล้วหยุด)
Host เตือนเรื่องนี้เสมอ และตั้งแต่ v2.0.4 **ส่งให้เครื่องประจำเตียงขึ้นเตือนด้วย** แต่ส่งเฉพาะเตียงที่เครื่องประจำเตียงประกาศว่ารู้จัก:

- Station ที่รู้จักใส่บิต `0x02` ใน `struct_message.flags` ทุกแพ็กเก็ต (Station 7.12.0, Station-Stable 7.5.9, Station-C3-OLED 1.4.0, Station-Fallout 1.6.0)
- Host อ่านบิตนี้ใหม่ทุกแพ็กเก็ต: เตียงที่ประกาศได้รหัส 6 ส่วน Station รุ่นเก่าได้ 0 เหมือนเดิม (ไม่เปลี่ยนโครงสร้างแพ็กเก็ต และรุ่นเก่าไม่ต้องแก้)
- เครื่องประจำเตียงที่ได้รหัส 6 ขึ้นจอเตือนเต็มจอ "NO DROP / CHECK DRIP SENSOR" ไฟสถานะเตือน และเสียงเฉพาะ (Active: 2 ครั้งสั้น · Passive: โทน 1400 Hz) พักเสียงได้เหมือนเตือนอื่น
- ถ้าเครื่องประจำเตียงเห็นหยดเองแล้ว (เซนเซอร์ทำงาน) จะไม่ขึ้น NO DROP แม้ Host ยังส่งรหัสค้างอยู่ชั่วขณะ
- Host อื่น (OLED, TFT, สัมผัส 2.4", CYD-LVGL) ยังไม่ส่งรหัส 6 ให้ Station จึงไม่ขึ้น NO DROP ที่เครื่องประจำเตียงเมื่อใช้คู่กัน ต้องใช้ Host-CYD28 v2.0.4
- หน้าเว็บ `/api/state` มีฟิลด์ `noDropSync` บอกว่าเตียงไหนประกาศรองรับ (ใช้ตรวจว่า Station เตียงนั้นอัปเดตแล้ว)

## ด่านที่ 4: เว็บ นาฬิกา SD ประวัติ

**เชื่อมต่อ** Host เปิดจุดเชื่อมต่อ Wi-Fi ชื่อ `SmartIV-Host` รหัส `12345678` (ตั้งใน `board.h`: `CYD_AP_SSID`, `CYD_AP_PASS` **ควรเปลี่ยนก่อนใช้งานจริง**)
ต่อมือถือหรือคอมพิวเตอร์เข้าจุดนี้ แล้วเปิด `http://192.168.4.1/` หน้า SYSTEM บนจอแสดงชื่อจุดเชื่อมต่อ SD และสถานะนาฬิกา
ภาพหน้าเว็บอยู่ที่ `docs/screens-cyd2/web_dashboard.png` (ภาพจากข้อมูลจริงที่เฟิร์มแวร์สร้าง)

| ทำอะไร | ต้องล็อกอินไหม |
|---|---|
| ดูสถานะเตียง ประวัติเหตุการณ์ | ไม่ต้อง |
| แก้ค่าตั้ง (อัตรา ปริมาตร drop factor เกณฑ์ใกล้หมด) · เริ่มถุงใหม่ (ถามยืนยัน และ API ต้องส่ง `confirm=1` อีกชั้น) · รับทราบใกล้หมด | **ต้อง** บัญชี `admin` / `smartiv` (`CYD_WEB_USER`, `CYD_WEB_PASS` เปลี่ยนได้) |
| ตั้งเวลา | ไม่ต้องเฉพาะครั้งแรกที่ Host ยังไม่เคยตั้งเวลา (เบราว์เซอร์ส่งให้เอง) หลังจากนั้นต้องล็อกอิน |

ค่าที่รับจากเว็บถูกตรวจเข้มงวดและใช้ทั้งชุดหรือไม่ใช้เลย (ตัวเลขต้องเป็นเลขฐานสิบล้วน ไม่รับ `1e5` `0x10` `nan` อยู่ในช่วงที่ปลอดภัย)
ผิดฟิลด์เดียว ไม่แก้ฟิลด์อื่นเลย การแก้ค่าจากหน้าจอ เว็บ และ Serial ผ่านฟังก์ชันเดียวกัน จึงลงประวัติเหมือนกันและไม่เคยแตะ `resetSeq`

**นาฬิกา** Host ไม่มีอินเทอร์เน็ต จึงรับเวลาจากเครื่องที่เปิดหน้าเว็บ แล้วส่งให้ Station ผ่าน Sync
ก่อนตั้งเวลา Host ส่งเวลา 0 และ `isSynced=0` เสมอ (ไม่บอก Station ว่าเวลาตรงทั้งที่ยังไม่ตั้ง) รีบูตแล้วต้องตั้งใหม่ถ้าไม่มี RTC
(Station ที่เคยได้เวลาแล้วยังเดินต่อเองได้) **ไม่มี NTP โดยตั้งใจ** เพราะต้องต่อเราเตอร์ ซึ่งบังคับให้ช่องสัญญาณ ESP-NOW ตามเราเตอร์
ตัวเลือก RTC DS3231: ตั้ง `CYD_RTC_SDA` และ `CYD_RTC_SCL` ใน `board.h` (ปิดไว้เป็นค่าปริยาย เพราะขา CN1 IO27/IO22 ตรงกับขาบัซเซอร์ GPIO27 ต้องย้ายบัซเซอร์ไปขาอื่นก่อน ตั้งชนกันแล้วคอมไพล์ไม่ผ่านโดยตั้งใจ)

**ประวัติเหตุการณ์** เก็บ 48 รายการล่าสุดในหน่วยความจำ (หายเมื่อรีเซ็ต) และบันทึกลง SD ที่ `/events.csv` คอลัมน์ `epoch,upSec,bed,event,detail`
(`epoch` เป็น 0 ถ้ายังไม่ตั้งเวลา) เหตุการณ์: BOOT, ALERT/CLEAR (พร้อมรหัสเตือน), ONLINE/OFFLINE, NEWBAG, CONFIG, ACK, SILENCE
ถ้าไม่มีการ์ดหรือเขียนล้มเหลวติดกันสามครั้ง ระบบเลิกใช้การ์ดเงียบๆ ไม่กระทบการเตือน
เตียงที่เงียบเกือบ 8 วินาทีจะขึ้น ALERT OCCLUSION ก่อนเข้า OFFLINE แล้วตามด้วย CLEAR (พฤติกรรมเดียวกับ Host รุ่น 1.x เพราะนับเวลาไม่มีหยดรวมอายุแพ็กเก็ต)

**ที่ไม่มีเมื่อเทียบกับรุ่น 1.x:** กราฟแนวโน้มและรายงานย้อนหลังรายนาที, การตั้งชื่อผู้ป่วย, หน้าตั้งค่า Wi-Fi/รหัสผ่านผ่านเว็บ (แก้ใน `board.h` แล้วอัปโหลดใหม่)

## ด่านที่ 3: หน้าจอและบัซเซอร์ Active

ภาพทุกหน้าอยู่ใน `docs/screens-cyd2/` (แนวนอน 320x240 เท่านั้น ตั้ง `CYD_ROTATION` เป็น 1 หรือ 3 ถ้าตั้งเลขคู่คอมไพล์จะไม่ผ่าน)

| หน้า | ใช้ทำอะไร |
|---|---|
| HOME | ซ้าย = เตียงที่ต้องดูตัวใหญ่ (เหตุวิกฤตก่อน แล้วใกล้หมด) · ขวา = รายการเตียง แตะเพื่อเปิด · ล่าง = SYS กับแถบเสียงเตือน (แตะเพื่อพักเสียง 2 นาที) |
| BED | อัตราไหล ปริมาตร เวลาที่เหลือ ลิงก์ · BACK / SET / NEW BAG (ถามยืนยันก่อน) / ACK (ใช้ได้เมื่อใกล้หมดและยังไม่รับทราบ) |
| BED SET | อัตราเป้าหมาย ปริมาตรถุง drop factor (แตะวน 10/15/20/60) เกณฑ์ใกล้หมด · SAVE / CANCEL |
| NUMPAD | ใส่ตัวเลข ค่านอกช่วงขึ้นกรอบแดงและกด OK ไม่ได้ (อัตรา 0-3000, ปริมาตร 0-10000, ใกล้หมด 50-95) |
| SYSTEM | จำนวนเตียง ความสว่าง สวิตช์เสียง ปุ่ม TEST คาลิเบรตทัช และตัวเลขวินิจฉัยเครือข่าย |

**ต่อบัซเซอร์ Active**
- ต่อที่ **GPIO27** (ขา IO27 ของขั้ว CN1) แก้ได้ด้วย `CYD_BUZZER_PIN` ใน `board.h` (`-1` = ไม่ต่อ) **ห้ามใช้ GPIO26** เพราะเป็นขาเข้าของวงจรขยายลำโพงบนบอร์ด ไม่ใช่ขาขับบัซเซอร์
- บัซเซอร์ที่กินกระแสไม่เกินราว 10 mA และใช้ 3.3 V ต่อขาเข้ากับ GPIO27 ได้ตรง ๆ (ขาอื่นของบัซเซอร์ลง GND) ถ้าเป็นแบบ 5 V หรือกินกระแสมากกว่านั้นให้ผ่านทรานซิสเตอร์ NPN
  (GPIO27 ผ่านตัวต้านทาน 1 kΩ เข้าขาเบส · ตัวส่งลง GND · ตัวเก็บต่อขั้วลบของบัซเซอร์ · ขั้วบวกต่อ 5 V) และคร่อมไดโอดกันไฟย้อนกลับถ้าเป็นแบบขดลวด
  **ตรวจชื่อขั้วบนบอร์ดของคุณกับผังวงจรของล็อตนั้นก่อนต่อ** ผมยังไม่ได้ลองกับบอร์ดจริง
- โมดูลบัซเซอร์ที่ทำงานเมื่อขาเป็น LOW ให้ตั้ง `CYD_BUZZER_ON_LEVEL` เป็น `LOW`
- เสียงที่ได้ยิน: **เสียงกด** สั้น ๆ ทุกครั้งที่แตะปุ่ม · **เสียงเตือน** แยกชนิดด้วยจำนวนครั้งต่อรอบ (บัซเซอร์ Active ปรับความถี่ไม่ได้)
  สายพับ 3 ครั้ง · เร็วเกิน 4 ครั้งถี่ · ช้าเกิน 1 ครั้งยาว · ครบแผน 2 ครั้ง · ไม่มีหยด 2 ครั้งสั้น · ขาดการติดต่อ 5 ครั้งสั้น
  หลายเตียงเตือนพร้อมกันจะร้องรหัสที่สำคัญที่สุด · ใกล้หมดเป็นเสียงเบา 3 ครั้งซ้ำทุก 5 นาทีจนกด ACK
- ปุ่มพักเสียง 2 นาที พักแล้วเหตุใหม่หลังเหตุเก่าหายจะดังทันที · สวิตช์เสียงอยู่ที่หน้า SYSTEM (ปิดแล้วเงียบทั้งเสียงกดและเสียงเตือน)
- **ไม่ได้ผ่านมาตรฐานเสียงเตือนทางการแพทย์ (IEC 60601-1-8)** และยังไม่ได้วัดความดังบนอุปกรณ์จริง

## ด่านที่ 2: ใช้งานกับ Station

1. อัปโหลด บอร์ดเริ่ม ESP-NOW ที่ช่อง 1 (`CYD_ESPNOW_CHANNEL`) ทันที ไม่ต้องคาลิเบรตก่อน หน้าจอแสดงตารางเตียง
2. ตั้งค่าเตียงทาง Serial (115200 จบบรรทัดด้วย Enter) ค่าถูกเก็บใน NVS และส่งให้ Station ทันที:
   `beds 5` จำนวนเตียงที่เปิดใช้ (1-8) · `rate 1 60` เป้าหมาย mL/h · `plan 1 500` ปริมาตรตามแผน mL ·
   `df 1 20` drop factor (10/15/20/60) · `near 1 80` เกณฑ์ใกล้หมด % · `newbag 1` เริ่มถุงใหม่ · `ack 1` รับทราบใกล้หมด · `table` พิมพ์ตาราง
3. Station เปิดแล้วควรเห็นเตียงขึ้น OK ภายในไม่กี่วินาที ถ้า Station ค้นหาช่องอยู่ มันจะหาช่อง 1 เจอเอง
4. `m` หรือกด BOOT สั้นๆ สลับไปหน้าทดสอบจอ/ทัช (ด่านที่ 1) กด BOOT ค้าง 1.5 วินาที = คาลิเบรตใหม่

**พฤติกรรมที่ตรงกับ Host รุ่นเดิม** (เพื่อให้ Station ทุกรุ่นคุยได้): ออฟไลน์เมื่อเงียบเกิน 8 วินาที · ขาดการติดต่อจริงเมื่อเงียบต่ออีก 30 วินาที
(เฉพาะเตียงที่กำลังนับ) · สายพับเมื่อไม่มีหยดเกิน 2.5 เท่าของช่วงหยดตามเป้า (ขั้นต่ำ 8 วินาที เพดาน 5 นาที) · เร็ว/ช้าเกินเมื่อเกิน 135%/ต่ำกว่า 65% ของเป้าต่อเนื่อง 20 วินาที
· ไม่มีหยดเลย 90 วินาที · ใกล้หมดที่ 80% (ตั้งได้ 50-95) · รหัส 7 (LOST_LINK) ใช้ภายใน Host ไม่ถูกส่งไป Station ส่วนรหัส 6 (NO_SIGNAL หรือ NO DROP) ส่งให้เฉพาะ Station ที่ประกาศว่ารู้จัก (ดูหัวข้อ NO DROP ข้างล่าง) รุ่นเก่าได้ 0 เหมือนเดิม

**ยังไม่มี:** นาฬิกา/ซิงก์เวลาให้ Station (ส่ง `epochTime=0` ซึ่ง Station เมิน), SoftAP/เว็บ/SD/ประวัติ (ด่านที่ 4)

## วิธีทดสอบบนบอร์ด (ด่านที่ 1: จอและทัช)

1. เลือกชิปจอตามพอร์ต USB: **สองช่อง = ST7789** (ค่าปริยาย `CYD_PANEL 7789` ตามผลจากบอร์ดจริงของผู้พัฒนา) · **ช่องเดียว = ILI9341** แก้ `CYD_PANEL` ใน `board.h` เป็น `9341` อาการที่บอกว่าตั้งผิดชิป: ภาพไม่เต็มจอ มีจุดสุ่มที่ขอบ และแดง/น้ำเงินสลับ (ตรวจด้วย `firmware/CYD-ColorTest`)
2. อัปโหลด เปิด Serial Monitor 115200 บอร์ดจะเข้าหน้าคาลิเบรตเอง (ยังไม่มีค่าในเครื่อง) แตะกากบาทสามจุดตามลำดับ
3. หน้าทดสอบแสดงแถบสี 8 สี ไล่เฉดเทา 16 ระดับ และช่องวาดตามนิ้ว ตรวจ:
   - **ดำต้องดำสนิท** (ช่องซ้ายสุดของไล่เฉดและแถบสุดท้าย) ถ้าซีดหรือเทา พิมพ์ `i` ใน Serial เพื่อสลับกลับสี
   - **แดง/น้ำเงินไม่สลับ** ถ้าสลับ พิมพ์ `b` (ใช้ได้กับ ST7789)
   - จุดสีเหลืองต้องตามปลายนิ้วตรงตำแหน่ง ถ้าเพี้ยนแตะ CAL หรือกด BOOT ค้าง 1.5 วินาที
4. ได้ค่าที่ถูกแล้วให้ตั้ง `CYD_INVERT` / `CYD_BGR` ใน `board.h` ตามนั้นแล้วอัปโหลดใหม่ (ค่าที่สลับผ่าน Serial หายเมื่อรีเซ็ต)

| คำสั่ง Serial | ผล |
|---|---|
| `h` | ช่วยเหลือ |
| `i` | สลับโหมดกลับสี |
| `b` | สลับ RGB/BGR (ST7789) |
| `r` | เปลี่ยนทิศจอ แล้วคาลิเบรตใหม่ |
| `c` | คาลิเบรตใหม่ |
| `+` / `-` | ความสว่างไฟหลังจอ |
| `d` | พิมพ์รหัสชิป ILI9341 (ควรได้ `00 93 41`) |

## ต่างจากรุ่น 1.x อย่างไร

- **คาลิเบรตแบบ affine สามจุด** แทนการเดาว่าแกนทัชสลับหรือไม่ จึงรองรับแกนสลับ กลับด้าน และเอียงในสมการเดียว
  ปฏิเสธจุดที่อยู่แนวเดียวกันหรือแตะที่เดิมซ้ำ ค่าที่เก็บใน NVS ผูกกับทิศจอ ขนาดจอ และชิปจอ ถ้าไม่ตรงจะคาลิเบรตใหม่เอง
- **ตัวติดตามนิ้ว** กรองสัญญาณสะดุดของทัชราคาถูก (ต้องเห็นกดสองครั้งติดกันจึงนับเป็น DOWN)
- **สวิตช์สีขณะรัน** หาค่าที่ถูกกับบอร์ดแต่ละใบได้โดยไม่ต้องคอมไพล์ใหม่

ตรวจคณิตศาสตร์คาลิเบรตกับแกนสามแบบ การปฏิเสธจุดเสีย ไดรเวอร์กับแบบจำลองชิป XPT2046 และรัน `setup()`/`loop()`
