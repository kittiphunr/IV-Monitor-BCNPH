# เครื่องส่วนกลางจอ TFT 2.8" รุ่นเกตเวย์ v1.0.0-TG

คู่กับ **Station-Thin** ผ่าน Protocol v4: Host คำนวณอัตราไหล ปริมาตร % เวลาที่เหลือ และตัดสินเตือน
แล้วส่งผลกลับให้จอ Station แสดง และส่งสรุปขึ้นพีซีแบบเดียวกับ Host-Gateway (ไม่เปิดเว็บเอง)

อ่านหลักการที่ [`docs/PROTOCOL-V4.md`](../../docs/PROTOCOL-V4.md) และ [`docs/GATEWAY-DESIGN.md`](../../docs/GATEWAY-DESIGN.md)

> **ยังไม่ได้ทดสอบบนฮาร์ดแวร์จริง** ตรวจด้วยตัวจำลองบน PC (`bash tools/v4-test/run.sh`)

## ที่มา

| ส่วน | มาจาก |
|---|---|
| จอ TFT ตรรกะเตือน ปุ่ม แบตเตอรี่ | Host-TFT28 4.9.1-TFT (ไม่แก้) |
| ลิงก์ขึ้นพีซี คำสั่งมีเลขลำดับ หน้าตั้งค่าครั้งแรก | Host-Gateway 1.0.0-GW (ไม่แก้) |
| รับ Protocol v4, ตัวคำนวณอัตราไหล, ส่งผลลง Station | ใหม่ในรุ่นนี้ |

`bash tools/gateway-sync/run.sh` เทียบฟังก์ชันที่ยกมากับต้นฉบับทีละบรรทัด

## ติดตั้งครั้งแรก

เหมือน Host-Gateway: เครื่องเปิด Wi-Fi ชื่อ `IV-Gateway-Setup` (รหัส `12345678`) ให้ต่อมือถือแล้วเปิด `http://192.168.4.1`
กรอกชื่อ/รหัส Wi-Fi ของเราเตอร์ ที่อยู่พีซี พอร์ต (ปริยาย 8080) และรหัสเกตเวย์ (ถ้ามี) กดบันทึกแล้วเครื่องรีสตาร์ต
ตั้งค่าใหม่ภายหลังด้วยการกดปุ่มเปลี่ยนหน้าค้างตอนเปิดเครื่อง 3 วินาที
พีซีใช้ `server/PC-Dashboard` ตัวเดียวกับ Host-Gateway

## ฮาร์ดแวร์

เหมือน Host-TFT28 ทุกขา (ESP32-S3 N16R8 + ST7789V 2.8" + Buzzer)

## ข้อควรรู้

- **รับเฉพาะ Station-Thin** แพ็กเก็ต Protocol v3 ถูกกรองทิ้ง ไม่ส่ง Sync แบบ v3
- จำนวนเตียงต่อเครื่องยังเป็น 8
- Host ไม่ตรวจเลขเตียงซ้ำ (ตามต้นฉบับ Host-TFT28 ที่ยังไม่มีฟีเจอร์นี้ ต่างจาก Host-OLED)
- ขณะเราเตอร์ล่ม การลองต่อใหม่ทำให้แพ็กเก็ตจากเตียงอาจหายชั่วคราว ใช้ backoff 10 วินาที → 5 นาที **ต้องวัดบนบอร์ดจริง**
- ถ้า Host ดับ จอ Station ทุกเตียงขึ้น NO HOST และไม่มีเสียงเตือนที่เตียง เพราะรหัสเตือนมาจาก Host อย่างเดียว

## ทดสอบ

```bash
bash tools/v4-test/run_host.sh   # รับ v4 คำนวณอัตรา ตัดสินเตือน ส่งผลลง รับคำสั่งพีซี
bash tools/v4-test/run.sh        # ชุดเต็ม รวมวงจรปิดกับ Station จริงและเซิร์ฟเวอร์พีซีจริง
```
