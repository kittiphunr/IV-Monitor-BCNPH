# เครื่องประจำเตียงแบบบาง v1.0.0-TH

แตกจาก Station 7.10.0 ให้เครื่องข้างเตียงเป็นแค่ **ตา** (ตรวจจับหยด) กับ **จอ** (แสดงผลที่ Host คำนวณมา)
ไม่มีสูตรคลินิกในเครื่องเลย อ่านหลักการที่ [`docs/PROTOCOL-V4.md`](../../docs/PROTOCOL-V4.md)

> **ยังไม่ได้ทดสอบบนฮาร์ดแวร์จริง** ตรวจด้วยตัวจำลองบน PC (`bash tools/v4-test/run.sh`)

## ใช้คู่กับ

**Host-TFT-Gateway เท่านั้น** (Protocol v4) ใช้กับ Host รุ่นอื่นหรือใช้ปนกันไม่ได้ ไม่เสียหาย แต่คุยกันไม่รู้เรื่อง

## ฮาร์ดแวร์

เหมือน Station ทุกขา (ESP32-S3 Super Mini + TFT 1.47" + เซนเซอร์ TCRT5000 + Buzzer) สลับเฟิร์มแวร์ได้โดยไม่ต้องแก้สายไฟ

## เครื่องทำอะไร / ไม่ทำอะไร

| | Station | Station-Thin |
|---|---|---|
| ตรวจจับหยดและเรียนรู้รูปคลื่น | ✅ | ✅ (`drop_detector.h` เหมือนกันทุกไบต์) |
| ยอดหยดสะสมรอดรีบูต/ไฟดับ | ✅ | ✅ |
| คำนวณอัตราไหล (หน้าต่าง 8 หยด) | ในเครื่อง | **ที่ Host** |
| ปริมาตร % เวลาที่เหลือ | ในเครื่อง | **ที่ Host** |
| ตัดสินสายพับ/ใกล้หมด/ครบแผน | ในเครื่อง | **ที่ Host** |
| จอ เสียง ไฟสถานะ ปุ่ม | ✅ | ✅ ไม่เปลี่ยน |

## ตรวจระดับแบตเตอรี่ (1.1.0-TH)

เครื่องตรวจแบตเตอรี่ของตัวเอง (เมื่อต่อวงจรวัดที่ `STATION_BAT_ADC_PIN`) ด้วย `battery_check.h` ตัวเดียวกับที่ Host ใช้

| ระดับ | แรงดัน | ที่จอ | เสียง |
|---|---|---|---|
| ปกติ | ≥ 3.50 V | ไม่มีอะไร (ไม่รกหัวจอ) | – |
| ต่ำ | < 3.50 V (~30%) | ไอคอนเหลืองที่หัวจอ + `LOW BATT` ในหน้า 3 | สองครั้งทุก 5 นาที |
| วิกฤต | < 3.35 V (~15%) | ไอคอนแดงกะพริบ + `BATT CRIT` | สามครั้งทุก 1 นาที |

- ต้องอยู่ในระดับใหม่ต่อเนื่อง **30 วินาที** จึงเปลี่ยน แรงดันตกตอนบัซเซอร์ดังจึงไม่ทำให้เตือนผิด (การอ่านครั้งแรกหลังเปิดเครื่องตัดสินทันที)
- ฮิสเทอรีซิส 50 mV ขาขึ้น แรงดันแกว่งรอบเส้นแบ่งไม่ทำให้ระดับสลับไปมา
- แรงดันแย่ลงจากต่ำเป็นวิกฤต เตือนวิกฤตทันที ไม่รอรอบของระดับต่ำ
- **ไม่มีวงจรวัด (ค่าปริยาย `STATION_BAT_ADC_PIN = -1`) หรือใช้ไฟ USB = ไม่ตรวจ ไม่เตือน** เครื่องที่ไม่ได้ต่อวงจรวัดจึงไม่มีการเตือนแบตเตอรี่เลย
- เป็นเรื่องบำรุงรักษา ไม่ใช่เหตุทางคลินิก เสียงเงียบเมื่อมีเหตุวิกฤตหรือเตือนใกล้หมดอยู่ และไม่ใช้สีแดงบนการ์ดสถานะ
- Host ได้แรงดันของเตียงนี้ในแพ็กเก็ตขึ้นอยู่แล้ว และตรวจซ้ำอีกชั้นที่ฝั่ง Host เผื่อเครื่องเตียงเตือนไม่ทัน (เช่น เสียงถูกปิด)

## เมื่อ Host หาย

จอไม่โชว์ค่าเก่าที่ไม่มีใครยืนยัน

| | แสดง |
|---|---|
| การ์ดสถานะ | **NO HOST** สีส้ม (ไม่ใช่ NORMAL สีเขียว) |
| อัตราไหล | `--` |
| ถุงน้ำเกลือ | ว่าง และ `-- LEFT` |
| นาทีที่เหลือ / เวลาเสร็จ / % | `--` |
| ปริมาตรที่ให้แล้ว | หยดสะสม ÷ drop factor (ข้อเท็จจริงล้วน ไม่ใช่ค่าประเมิน) |
| เสียงเตือน | ไม่มี (รหัสเตือนมาจาก Host อย่างเดียว) |

**นี่คือข้อแลกเปลี่ยนโดยตั้งใจ** ถ้าวอร์ดต้องการให้เครื่องข้างเตียงเฝ้าได้เองเมื่อ Host ดับ ให้ใช้ Station สายหลัก
เครื่องยังส่งข้อมูลขึ้น Host ต่อเนื่อง และ Host จะกลับมาแสดงผลได้ทันทีที่ได้ยินกัน
