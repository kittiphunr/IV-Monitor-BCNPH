# PC Dashboard v1.0.0-PC

โปรแกรมฝั่งพีซีสำหรับ Host-Gateway: รับสถานะทุกเตียง เก็บประวัติลง SQLite
และเสิร์ฟ **หน้าเว็บเดิมของ Host-OLED** ให้พยาบาลเปิดจากเบราว์เซอร์

ใช้เฉพาะไลบรารีมาตรฐานของ Python 3.8 ขึ้นไป **ไม่ต้อง pip install อะไร**

## รัน

```bash
python3 server.py
```

```bash
python3 server.py --port 8080 --token รหัสเกตเวย์ --auth admin:รหัสผ่านหน้าเว็บ
```

เริ่มแล้วจะพิมพ์ที่อยู่ของพีซีออกมา เอาไปกรอกที่ Setup Portal ของ Host-Gateway
และเปิดหน้าเว็บที่ `http://<ที่อยู่พีซี>:8080`

| ตัวเลือก | ปริยาย | |
|---|---|---|
| `--port` | 8080 | พอร์ต ต้องเปิดไฟร์วอลล์ขาเข้าให้ Host และเครื่องที่เปิดหน้าเว็บ |
| `--db` | `iv_history.sqlite` ข้างโปรแกรม | ไฟล์ประวัติ สำรองด้วยการคัดลอกไฟล์นี้ |
| `--token` | ว่าง | ถ้าตั้ง Host ต้องใส่รหัสเดียวกัน ไม่ตรง = 403 (หรือตัวแปรสภาพแวดล้อม `IV_GATEWAY_TOKEN`) |
| `--auth` | ว่าง | `user:password` ของหน้าเว็บ (หรือ `IV_DASH_AUTH`) |
| `--bind` | `0.0.0.0` | ใช้ `127.0.0.1` ถ้าให้เฉพาะพีซีเครื่องนี้เข้า |

**ตั้ง `--auth` ทุกครั้งที่ใช้จริง** ข้อมูลมีชื่อผู้ป่วย และการส่งเป็น HTTP ธรรมดาในเครือข่ายภายใน

## ข้อมูลที่เก็บ

- บันทึกรายนาทีต่อเตียง (หยด ปริมาตร อัตรา เป้าหมาย รหัสเตือน RSSI แบตเตอรี่) แยกตาม "ถุง"
  กด "เริ่มถุงใหม่" จะเปิดถุงใหม่ ประวัติถุงเก่ายังอยู่ในฐานข้อมูล หน้าเว็บและ CSV แสดงถุงปัจจุบัน
- ขณะ Host เงียบ จะ **ไม่เขียนแถวใหม่** ช่องว่างในกราฟคือความจริง


```bash
bash ../../tools/gateway-test/run.sh
```

คำสั่งหลังรันเฟิร์มแวร์ Host-Gateway จริงบน PC คู่กับเซิร์ฟเวอร์ตัวนี้

## หน้าเว็บ

`static/dashboard.html` เป็นสำเนาที่สร้างจาก `firmware/Host-OLED/web_dashboard.h` ห้ามแก้ด้วยมือ

```bash
python3 extract_dashboard.py          # สร้างใหม่หลังแก้ web_dashboard.h
python3 extract_dashboard.py --check  # ตรวจว่าตรงต้นฉบับ
```

ตอนเสิร์ฟ โปรแกรมปะหน้าเว็บสามจุด: ถอดช่องตั้งค่า Wi-Fi ของ Host ออก,
เปลี่ยนหน้าต่าง "จุดเชื่อมต่อ" เป็นสถานะ Host-Gateway, เพิ่มแถบแดงเมื่อพีซีไม่ได้รับข้อมูลจาก Host
ถ้าหน้าเดิมเปลี่ยนจนหาจุดปะไม่เจอ โปรแกรมจะล้มทันทีตอนเริ่ม ไม่เสิร์ฟหน้าครึ่ง ๆ กลาง ๆ

โปรโตคอลที่คุยกับ Host: [`docs/GATEWAY-PROTOCOL.md`](../../docs/GATEWAY-PROTOCOL.md)
