# Screen Preview — พรีวิวหน้าจอ TFT บนเครื่อง PC

เครื่องมือเล็ก ๆ สำหรับดูผลหน้าจอ **จากไฟล์ .ino ตัวจริง** โดยไม่ต้องแฟลชลงบอร์ด
ช่วยให้ตรวจผังหน้าจอ ตัวอักษรล้นกรอบ หรือสีที่อ่านยาก ได้ตั้งแต่ก่อนขึ้นฮาร์ดแวร์

```bash
./run.sh                 # ผลลัพธ์ไปที่ docs/screens/
./run.sh /tmp/myscreens  # หรือระบุปลายทางเอง
```

ต้องมี: `g++` (C++17) และ `python3` + `pillow` (`pip install pillow`)

## หลักการทำงาน

1. `Arduino.h`, `Adafruit_GFX.h`, `Adafruit_ST7789.h`, `SPI.h`, `Preferences.h` ในโฟลเดอร์นี้
   เป็น **API จำลอง** ฝั่ง PC โดย GFX จะไม่วาดจริงแต่บันทึกคำสั่งวาดทุกคำสั่งลงไฟล์ข้อความ
2. `driver.cpp` `#include` ตัวสเก็ตช์เข้ามาตรง ๆ แล้วเดินเวลาเสมือน ~85 วินาที
   (เปิดโหมดจำลอง 60 mL/h ให้มีข้อมูลกราฟ) จากนั้นสั่งเปิดทีละหน้าและทำเครื่องหมายจุดที่ต้องการภาพ
3. `render.py` อ่านคำสั่งวาดมาประกอบเป็นภาพ PNG ขนาด 172x320 (ขยาย 3 เท่า)

## ข้อจำกัด

* ตัวอักษรเรนเดอร์ด้วย **ฟอนต์ 5x7 ตัวจริงของ Adafruit_GFX** (`fonts/glcdfont.c`)
  ตามขั้นตอนของ `Adafruit_GFX::drawChar()` ทีละพิกเซล จึงเป็นรูปเดียวกับจอจริง
  ข้อความที่ไม่ใช่ ASCII จะขึ้นเป็นสัญลักษณ์ตัวละไบต์แบบจอจริงเช่นกัน และตัวเรนเดอร์จะเตือนไว้
  (ที่มาของฟอนต์ดู `fonts/README.md`)
* มุมโค้งของกรอบและเส้นทแยงมุมเป็นการประมาณด้วย PIL
* ใช้ตรวจ "ผัง" ได้แม่นยำ แต่การตัดสินเรื่องสีจริงบนจอควรยืนยันกับฮาร์ดแวร์อีกครั้ง

## ตรวจการวาดล้นขอบจอ

ไฟล์ `ops.txt` ที่สร้างระหว่างทางสามารถนำไปตรวจพิกัดได้ เช่น หาคำสั่งที่ออกนอกกรอบ 172x320
(ดูตัวอย่างสคริปต์สั้น ๆ ในประวัติการพัฒนา หรือเขียนเพิ่มได้ตามต้องการ)
